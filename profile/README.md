### What we do

Argusic agents install, launch, debug and verify real open source software on a clean machine, with no human help. Every project gets a verdict backed by logs and a terminal recording. The rules are public: [methodology](https://argusic.com/methodology).

### Projects

- [**does-it-run**](https://github.com/argusic/does-it-run): Auto-generated results of the Argusic benchmark: does it run on a clean machine. Data CC BY 4.0, source argusic.com.
